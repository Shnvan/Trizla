## Codes

Reply:

- N: no reply yet.
- I: interested.
- M: maybe later.
- NF: not a fit.
- NS: no sensitive text use.
- B: already built or uses own workflow.

Tried Trizla:

- NT: not tested.
- OW: opened or watched only.
- DT: did one test.
- RT: repeated tests.

Pain level:

1. Never pastes sensitive text into AI.
2. Does it but does not think about it.
3. Worried but has not acted.
4. Actively redacts manually before pasting.
5. Has been burned, blocked, audited, or warned.

Willing to pay:

- N: no.
- W: waitlist or wants updates.
- C: verbally committed.
- P: paid.
